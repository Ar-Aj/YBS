# Bklit UI source

ShimmeringText.tsx comes from https://ui.bklit.com/r/shimmering-text.json
(repository: https://github.com/bklit/bklit-ui), retrieved 2026-11-18.
MIT license included in LICENSE. Only its cn/Tailwind utility styling was
replaced with inline defaults and a CSS Modules class. Motion API retained.
The homepage uses a single sweep on entering view, and respects reduced motion.
No Studio code is included. No new runtime dependencies are required.
