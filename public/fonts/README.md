# Website fonts

These WOFF2 files are byte-for-byte copies of Inter and Playfair Display from the successful next/font/google build. Definitions in src/app/fonts.css preserve the original weights, styles, Unicode ranges and fallback metrics.

Fonts are bundled so production builds do not depend on the Google Fonts download/resolver step. Keep these files in source control.
